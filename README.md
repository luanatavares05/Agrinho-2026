# 🌱 Caminhos do Agro Sustentável

## Sobre o projeto

Este site foi desenvolvido para o Agrinho 2026 com o tema:

"Agro Forte, Futuro Sustentável: equilíbrio entre produção e meio ambiente."

O objetivo é apresentar práticas agrícolas sustentáveis que unem tecnologia, produção e preservação ambiental.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página informativa sobre agricultura sustentável
- Quiz interativo
- Calculadora agrícola
- Feirinha sustentável
- Botões de acessibilidade
- Modo escuro
- Aumento e diminuição de fonte

## Temas abordados

- Manejo Integrado de Pragas (MIP)
- Agricultura regenerativa
- Agricultura orgânica e agroecológica
- Agricultura de Baixo Carbono (ABC)
- Integração Lavoura-Pecuária-Floresta (ILPF)
- Sistemas agroflorestais
- Silvicultura

## Objetivo do Agrinho 2026

Mostrar que é possível produzir alimentos e desenvolver o agronegócio preservando os recursos naturais e construindo um futuro sustentável.

Projeto desenvolvido para o concurso Agrinho 2026.
